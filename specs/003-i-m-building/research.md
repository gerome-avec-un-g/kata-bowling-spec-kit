# Research Findings: Bowling Score Calculator API

## Resolved Clarifications

### Target Platform

- **Decision**: Server environment (e.g., Linux server)
- **Rationale**: The feature description specifies a "REST API", which is typically deployed on a server. A Linux server environment is a common and suitable choice for hosting such applications.
- **Alternatives considered**: Cloud-based serverless functions (e.g., AWS Lambda, Azure Functions), containerized deployments (e.g., Docker, Kubernetes). These were not chosen as the default to keep the initial scope simple, but could be considered in future iterations.
